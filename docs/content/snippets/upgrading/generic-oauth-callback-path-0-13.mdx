### Generic OAuth callback path

Only for apps using the `genericOAuth()` plugin.

Better Auth 1.7 serves Generic OAuth callbacks at the standard social callback,
`/api/auth/callback/<providerId>`, and no longer serves
`/api/auth/oauth2/callback/<providerId>`. Update the redirect URI registered
with each provider, and any `redirectURI` you set in a provider config, to the
new path.

```ts
redirectURI: `${siteUrl}/api/auth/oauth2/callback/slack`, // [!code --]
redirectURI: `${siteUrl}/api/auth/callback/slack`, // [!code ++]
```
