### Remove `getStaticAuth`

In `convex/betterAuth/auth.ts`, replace `getStaticAuth(createAuth)` with
`createAuth({} as any)`.

<Callout>
  This file should contain _only_ the `auth` export for schema generation.
  Importing it at runtime causes errors from missing environment variables.
</Callout>

```ts title="convex/betterAuth/auth.ts"
import { getStaticAuth } from "@convex-dev/better-auth"; // [!code --]
import { v } from "convex/values";
import { createAuth } from "../auth";

// Export a static instance for Better Auth schema generation
export const auth = getStaticAuth(createAuth); // [!code --]
export const auth = createAuth({} as any); // [!code ++]
```
