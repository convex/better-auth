### Convex plugin endpoint keys renamed

The Convex plugin's `getToken`, `getJwks` and `getOpenIdConfig` endpoints are
renamed to `getConvexToken`, `getConvexJwks` and `getConvexOpenIdConfig`. Better
Auth merges plugin endpoints by key, so the `jwt` plugin, or any other plugin
with an endpoint of the same name, could replace the Convex plugin's endpoints.
The HTTP paths (`/convex/token`, `/convex/jwks`,
`/convex/.well-known/openid-configuration`) and `authClient.convex.token()` are
unchanged. If your server code calls `auth.api.getToken()`,
`auth.api.getJwks()` or `auth.api.getOpenIdConfig()` to reach the Convex
endpoints, call `auth.api.getConvexToken()`, `auth.api.getConvexJwks()` or
`auth.api.getConvexOpenIdConfig()` instead.
