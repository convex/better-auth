### `twoFactor.enable()` returns a discriminated union

If your app uses the two-factor plugin, `authClient.twoFactor.enable()` now
returns `{ method: "otp" }` or `{ method: "totp", totpURI, backupCodes }`. Check
`method` before reading `totpURI`.

```ts
const { data } = await authClient.twoFactor.enable({ password });
if (data?.totpURI) { // [!code --]
if (data?.method === "totp") { // [!code ++]
  setTotpUri(data.totpURI);
}
```
