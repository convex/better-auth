### Generic OAuth sign-in moved to `signIn.social`

Better Auth 1.7 removed `authClient.signIn.oauth2()` and the
`genericOAuthClient()` plugin, so remove the plugin from your auth client. Sign
in to Generic OAuth providers with `authClient.signIn.social()`, passing the
`providerId` from your `genericOAuth()` config as `provider`.

```ts title="auth-client.ts"
import { genericOAuthClient } from "better-auth/client/plugins"; // [!code --]

export const authClient = createAuthClient({
  plugins: [
    genericOAuthClient(), // [!code --]
    convexClient(),
  ],
});
```

```ts
await authClient.signIn.oauth2({ providerId: "slack" }); // [!code --]
await authClient.signIn.social({ provider: "slack" }); // [!code ++]
```
