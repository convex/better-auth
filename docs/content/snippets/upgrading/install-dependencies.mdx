### Install dependencies

Install the latest component and Better Auth `1.7.16` or a later `1.7.x`
release, even if you're several releases behind. You don't need to install
anything in between.

```npm
npm install @convex-dev/better-auth@^0.13.0
npm install better-auth@~1.7.16
```

<Callout>
  Review the breaking changes in each Better Auth release between your version
  and 1.7: [1.4](https://www.better-auth.com/blog/1-4),
  [1.5](https://www.better-auth.com/blog/1-5),
  [1.6](https://better-auth.com/blog/1-6), and the [1.7 upgrade
  guide](https://better-auth.com/docs/guides/1-7-upgrade-guide).
</Callout>

<Callout>
  Upgrade any other Better Auth packages in your dependencies, such as
  `@better-auth/expo`, to the same version.
</Callout>
