### Install dependencies

Install the latest component and Better Auth. Better Auth must be `1.7.14` or
later in the `1.7.x` line. Install these versions only, even if you're several
versions behind.

```npm
npm install @convex-dev/better-auth@^0.13.0
npm install better-auth@~1.7.14
```

<Callout>
  Review the breaking changes in each Better Auth release between your version
  and 1.7: [1.4](https://www.better-auth.com/blog/1-4),
  [1.5](https://www.better-auth.com/blog/1-5),
  [1.6](https://better-auth.com/blog/1-6), and the [1.7 upgrade
  guide](https://better-auth.com/docs/guides/1-7-upgrade-guide).
</Callout>

<Callout>
  Check your dependencies for other Better Auth packages, such as
  `@better-auth/expo`, and upgrade them to the same version.
</Callout>
