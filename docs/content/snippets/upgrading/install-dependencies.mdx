### Install dependencies

Install the latest component and Better Auth. Better Auth must be `1.6.11` or
later in the `1.6.x` line. Install these versions only, even if you're several
versions behind.

```npm
npm install @convex-dev/better-auth@^0.12.0
npm install better-auth@~1.6.15
```

<Callout>
  Review the breaking changes in each Better Auth release between your version
  and 1.6: [1.4](https://www.better-auth.com/blog/1-4),
  [1.5](https://www.better-auth.com/blog/1-5), and
  [1.6](https://better-auth.com/blog/1-6).
</Callout>

<Callout>
  Check your dependencies for other Better Auth packages, such as
  `@better-auth/expo`, and upgrade them to the same version.
</Callout>
