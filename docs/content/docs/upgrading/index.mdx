---
title: Upgrading
description: Upgrade @convex-dev/better-auth to the latest version
---

Each guide upgrades `@convex-dev/better-auth` from one version, 0.9 or later, to
the latest version. You don't need to upgrade one version at a time. Open the
guide for the version you're on, work through it, and deploy once. Local Install
projects that use organization teams and already have teams deploy twice, as the
guide's Regenerate schema step explains.

Older versions have known security issues. See [Security](/security).

To check your current version:

```npm
npm ls @convex-dev/better-auth
```
