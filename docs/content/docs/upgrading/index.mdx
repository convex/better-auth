---
title: Upgrading
description: Upgrade @convex-dev/better-auth to the latest version
---

Each guide upgrades `@convex-dev/better-auth` from a starting release, 0.9 or
later, straight to the latest, so you don't step through the releases in
between. Open the guide for your current version, work through it, and deploy
once. If you use Local Install and your database already has organization teams,
you need a second deploy, described in the guide's Regenerate schema step.

Older versions have known security issues. See [Security](/security).

To see which version you're on:

```npm
npm ls @convex-dev/better-auth
```
