These guides upgrade a project on any version from 0.9 onward to the current
version of `@convex-dev/better-auth`. You don't need to upgrade one version at a
time. Pick the version you're on, work through that guide, and deploy once.

To check your current version:

```npm
npm ls @convex-dev/better-auth
```
