## Supported versions

Only the latest version of `@convex-dev/better-auth` is supported, as in Better
Auth's
[security policy](https://github.com/better-auth/better-auth/blob/main/SECURITY.md).
Fixes, including security fixes, ship in the latest version. To update, follow
the [Upgrading](/upgrading) guide for your current version.

## Older versions

Older versions of the component use older Better Auth versions, which may be
affected by Better Auth advisories fixed in later releases. Check
[Better Auth's advisories](https://github.com/better-auth/better-auth/security/advisories)
against the Better Auth version that your component version uses:

| Component | Better Auth     |
| --------- | --------------- |
| 0.9       | 1.3             |
| 0.10      | 1.4             |
| 0.11      | 1.5             |
| 0.12      | 1.6             |
| Latest    | 1.7.14 or later |

If your component version accepts a range of Better Auth versions, you can
install the latest Better Auth patch in that range. Otherwise, upgrade the
component to the latest version.

## Reporting a vulnerability

Report potential vulnerabilities to
[security@convex.dev](mailto:security@convex.dev). Please don't disclose a
vulnerability publicly until we have addressed it.
